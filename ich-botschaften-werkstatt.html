Das Konfliktgespräch

Ich-Botschaften-Werkstatt

Sechs Vorwürfe, wie sie in jedem Betrieb fallen. Übersetzen Sie jeden Vorwurf in eine Ich-Botschaft mit den vier Schritten nach Marshall Rosenberg: Beobachtung, Gefühl, Bedürfnis, Bitte.

Die Werkstatt prüft Ihren Text auf typische Stolperfallen und zeigt Ihnen danach eine mögliche Formulierung. Es gibt nicht die eine richtige Lösung. Wichtig ist, dass Sie Ihre Formulierung so auch sagen würden.

Ihr Fortschritt bleibt in diesem Browser gespeichert, auch wenn Sie die Folie wechseln. Er wird nicht übermittelt.

Der Vorwurf

Sie haben alle sechs Vorwürfe übersetzt. Bevor Sie weitergehen, ein paar Gedanken zur Praxis.

Für den AlltagIm echten Gespräch klingt eine Ich-Botschaft selten so vollständig wie in dieser Werkstatt. Das muss sie auch nicht. Wenn Sie nur eines mitnehmen, dann dies: Beginnen Sie mit einer Beobachtung statt mit einem Urteil. Allein das verändert die Reaktion Ihres Gegenübers spürbar.
